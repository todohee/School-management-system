# CLI School Management System (Terminal Moodle)

> **Archive Notice:** This project was originally developed in 2024 as an early programming project. It is preserved here for portfolio and archival purposes to demonstrate past work. The repository is no longer actively maintained or updated.

A lightweight, command-line interface (CLI) school management system designed to replicate core learning management features directly in the terminal. Built for efficiency, this system allows administrators and instructors to manage students, courses, attendance, and grades without the overhead of a graphical interface.

## 🚀 Features

* **Student Management:** Add new students, update profiles, and manage enrollments.
* **Course Catalog:** Create courses, assign instructors, and enroll students.
* **Gradebook:** Input and modify grades for assignments and exams, and automatically calculate course averages or GPAs.
* **Attendance Tracking:** Log daily attendance for specific courses and generate attendance reports.
* **Interactive CLI Menu:** Easy-to-navigate terminal menus with input validation.
